# Runifly

Runifly is a React app built with VITE and ANTD that revolutionizes your running experience by seamlessly integrating the energizing power of music with your fitness goals. Whether you're preparing for a marathon, setting a new personal record, or enjoying a leisurely jog, Runifly ensures your music is in perfect sync with every step you take.

## Getting Started

To get started with Runifly, follow these steps:

1. Clone the repository: `git clone https://github.com/your-username/runifly.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser and visit `http://localhost:3000`
